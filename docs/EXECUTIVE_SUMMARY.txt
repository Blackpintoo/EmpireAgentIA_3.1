BREAKDOWN OF THE PROBLEM
================================================================================

LAYER 1: ORCHESTRATOR QUALITY GATES (VERY RESTRICTIVE)
├─ min_score_for_proposal: 8.0 (standard: 2-3) ← EXTREMELY HIGH
├─ min_confluence: 5 agents (standard: 2-3) ← EXTREMELY HIGH
├─ weighted_threshold: 3.0 (was 1.5) ← RESTRICTIVE
└─ min_rr_required: 1.8 ← HIGH

    Problem: A score of 8.0 on a 0-10 scale is near-perfect signal.
             In volatile markets, even 7.5 is rare. Most trades rejected here.

    Estimated block rate: 70-90%

LAYER 2: SESSION & HOUR FILTERS (TIME-BASED BLOCKS)
├─ Global blocked hours (UTC): [0,1,2,3,4,5,18,19,20,21,22,23] ← 12 hours
├─ Low-liquidity hours: [0,1,5,6,7,9,10,11,13,14,17,19,20,21] ← 14 hours avoided
├─ Effective open window: ~4-8 hours per day maximum
└─ Symbol-specific:
    ├─ LTCUSD: DISABLED
    ├─ AUDUSD: DISABLED
    ├─ SOLUSD: [13,23] only 2 hours ← EXTREME
    ├─ LTCUSD: [8,18,22] only 3 hours ← EXTREME
    └─ BNBUSD: Most hours blocked [0-5,18-23]

    Problem: Even if signal is strong, wrong time = rejected.
             Many symbols only available 2-3 hours per day.

    Estimated block rate: 60%+ of proposals

LAYER 3: MULTI-TIMEFRAME CONFLUENCE (ALIGNMENT REQUIREMENT)
├─ min_alignment_ratio: 0.7 ← 70% of timeframes must align!
├─ block_counter_trend: true ← Must not go against D1/H4
└─ require_higher_tf_confirm: true

    Problem: Requires 70% of [D1, H4, H1, M30, M15, M5, M1] aligned.
             In ranging markets, this is nearly impossible.

    Estimated block rate: 40-50%

LAYER 4: VOLATILITY FILTERS
├─ atr_spike_threshold: 2.0 ← Block if ATR doubled
├─ max_spread_atr_ratio: 0.3 ← Spread < 30% ATR
└─ gap_threshold_atr: 0.5 ← Gap < 50% ATR

    Problem: Natural market movements trigger these.
             During volatile sessions, all trades blocked.

    Estimated block rate: 30%

LAYER 5: POSITION & COOLDOWN LIMITS
├─ max_open_total: 2 ← Only 2 positions maximum
├─ after_trade_min: 15 ← Wait 15 min after every trade
├─ after_loss_min: 30-60 ← Wait 30-60 min after loss
└─ after_streak_min: 120 ← Wait 2 HOURS after 3 losses!

    Problem: Creates "lockout" periods where trading stops.
             After 3 losses, 2-hour pause prevents recovery.

    Estimated block rate: Variable, but 120-min pause is severe

LAYER 6: SYMBOL ENABLEMENT STATUS
├─ LTCUSD: enabled = false ← DISABLED
├─ AUDUSD: enabled = false ← DISABLED
├─ GBPUSD: max_trades_per_day = 1 ← Only 1 trade allowed!
├─ UK100: max_trades_per_day = 1 ← Only 1 trade allowed!
└─ SOLUSD: allowed_hours = [13,23] ← Only 2 hours!

    Problem: 4 of 13 symbols severely restricted or disabled.
             Only 9 symbols available.

    Effective symbols: 6-7 (not 13)

LAYER 7: KILL SWITCHES
├─ Daily loss limit: $400 USD ← Stops ALL trading if exceeded
└─ Circuit breaker: 5 errors in 60 sec ← Triggers kill switch

    Problem: One bad trading day stops everything.
             In volatile markets, $400 loss happens fast.

  - Result: Appears as "zero trades"

  1. Lower orchestrator quality thresholds (min_score, min_confluence)
